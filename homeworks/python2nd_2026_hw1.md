# Домашнее задание №1 — Настройка GitHub-репозитория

**Дедлайн: 02.10.2026, 23:59**

В рамках курса все домашние задания будут выполняться и сдаваться через GitHub в один и тот же ваш личный __приватный__ репозиторий.

> __Чтобы мы не потеряли ваш репозиторий, заполните, пожалуйста, эту [форму](https://docs.google.com/forms/d/e/1FAIpQLSfEzyvjA8tTR5WjwVtI7RL4HD1rXgrFwkch2P6KAO99SD0Wiw/viewform?usp=publish-editor).__

Для каждой домашней работы необходимо будет:

* создавать отдельную ветку;
* выполнять каждое задание отдельным коммитом (промежуточные с правками, конечно, допускаются);
* создавать Pull Request в `main`;
* после проверки и получения оценки делать merge в `main`.

Цель первого задания — настроить репозиторий и познакомиться с этим workflow. Чтобы потом у вас все работало :)

## Что нужно сделать?

Создание ветки, файлов и коммитов, а также отправку ветки выполняйте через терминал. Репозиторий, приглашения преподавателям и Pull Request можно оформить через интерфейс GitHub. Это будет оцениваться!

### 1. Создать репозиторий (1.25 баллов)

Создайте новый **приватный репозиторий** на GitHub.

Название репозитория:

`<название-курса>-<ваша-фамилия>-<группа-числом>`

Например:

`python2nd-ivanov-253`

Основной веткой репозитория должна быть `main`.

Добавьте в репозиторий файл `README.md` с вашим ФИО, группой и названием курса (это все еще происходит в `main`).

### 2. Выдать доступ преподавателям (1.25 баллов)

Добавьте преподавателей курса в созданный репозиторий в качестве **Collaborators** (Settings -> Collaborators -> Add People).

Список GitHub-аккаунтов преподавателей:

* `@tokubetsu`
* `@veronikatsareva`
* `@kopyloveta`
* `@urufjh`
* `@ewriusi`

Сделайте скриншот, что вы отправили приглашения, и положите его в репозиторий.

### 3. Создать ветку домашнего задания (1.25 баллов)

Создайте новую ветку:

`homework-01`

Все задания ниже выполняйте в **этой** ветке.

### 4. Task 1 — JSON (2 балла)

Создайте файл:

`homework-01/task-01.json`

Запишите в него информацию о себе в формате JSON. Файл должен содержать минимум три поля. Убедитесь, что файл содержит корректный JSON.

**После выполнения задания создайте отдельный коммит.**

Пример сообщения коммита:

```text
Add task 01
```

### 5. Task 2 — Markdown (2 балла)

Создайте файл:

`homework-01/task-02.md`

Напишите в нем последовательность команд в терминале, которые позволили вам сделать Task 1. Начните с создания ветки и закончите командой создания коммита. Будет идеально, если создание файла вы тоже сделаете через терминал.

**После выполнения задания создайте отдельный коммит.**

### 6. Создать Pull Request (1.25 балла)

Отправьте ветку `homework-01` на GitHub и создайте Pull Request:

`homework-01` → `main`

В описании Pull Request укажите:

* что было сделано;
* есть ли вопросы или проблемы, о которых проверяющему стоит знать.

**До проверки и получения оценки оставьте Pull Request открытым и не выполняйте merge.** Он будет использоваться проверяющим для проверки работы и оставления комментариев.

### 7. Исправления по комментариям
- Оценивается в 0 баллов, если комментарии были исправлены (или комментариев нет и исправлять было нечего)
- Штраф 0.5 балла, если были комментарии, но их не исправили

Если проверяющий оставил комментарии в Pull Request, внесите необходимые исправления в той же ветке.

Исправления оформляйте **новыми коммитами**.

Не изменяйте и не удаляйте уже существующие коммиты.

### 8. Завершение работы (1 балл)

После проверки и получения оценки:

1. Вмерджите Pull Request в `main`;
2. Убедитесь, что изменения появились в `main`;
3. После этого ветку `homework-01` можно удалить.

## Что будет проверяться

* Репозиторий создан как приватный.
* Преподавателям и ассистентам выдан доступ к репозиторию.
* Основная ветка называется `main`.
* Создана ветка `homework-01`.
* `task-01.json` содержит корректный JSON.
* `task-02.md` корректно оформлен в Markdown.
* Task 1 и Task 2 находятся в разных коммитах.
* Сообщения коммитов понятные.
* Создан Pull Request `homework-01` → `main`.
* После проверки Pull Request вмерджен в `main`.
